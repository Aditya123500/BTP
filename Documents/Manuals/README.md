# Project Documentation

This folder contains the maintained specifications and operating guides for the equity research backtest pipeline. Start with the [Operational Manual](Operational_Manual.md) to run it, the [Functional Specification](Functional_Specification.md) to understand the strategy behavior, or the [Technical Specification](Technical_Specification.md) to understand components and data flow.

## Documents

| Document | Purpose |
|---|---|
| [Contract](Contract.md) | Scope, deliverables, assumptions, acceptance checks, and known limitations. |
| [Technical Specification](Technical_Specification.md) | Architecture, flow, input/output data, components, and failure handling. |
| [Functional Specification](Functional_Specification.md) | Strategy rules, trading behavior, costs, risk controls, and reports. |
| [Operational Manual](Operational_Manual.md) | Setup, prerequisites, required files, run procedures, checks, and troubleshooting. |
| [Command Reference](Command_Reference.md) | Pipeline and script commands, switches, defaults, and examples. |
| [Quick Commands](Quick_Commands.md) | Common copy/paste commands for setup, run, inspect, and validate. |
| [Version History](Version_History.md) | Versions identifiable from the repository and the release records available. |
| [Strategy specifications](Strategies/) | Individual functional and operational notes for [CODE1](Strategies/CODE1.md), [CODE2](Strategies/CODE2.md), [CODE3](Strategies/CODE3.md), and [CODE4](Strategies/CODE4.md). |

The root [`README.md`](../../README.md) remains the short project overview and results summary. The QBEAST bundle has its own detailed documentation in [`QBEAST_circuit_flags_v2.4.4`](../../QBEAST_circuit_flags_v2.4.4/README.md), including the flag rules and bundle file reference.

These documents describe the implementation and data currently present in this repository. They do not certify live trading readiness or reproduce proprietary index methodologies where required inputs or official formulas are unavailable.
