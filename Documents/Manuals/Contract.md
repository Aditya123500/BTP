# Project Contract

This repository runs four historical equity strategy backtests with QBEAST v2.4.4 trade blocking. It is a research tool, not a live trading system.

**Included:** CODE1–CODE4, QBEAST EOD flags, costed portfolio results, benchmarks, and run documentation.

**Run acceptance:** required inputs exist; QBEAST completes or complete matching flags are reused; all strategies finish and write outputs; commands, config, data coverage, and validation results are saved.

**Limits:** strategies are proxies, data coverage is incomplete, default costs omit taxes/fees/market impact/capacity, and historical results do not predict future returns. No ETF or intraday real-history evaluation is included in the saved run.

Changes to strategy rules, costs, gate behavior, or input/output formats must be reflected in the relevant guide and version history.
